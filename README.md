AlphaParser: Quantitative Trading DSL Transpiler
AlphaParser is a custom source-to-source compiler designed to bridge the gap between high-level quantitative strategy research and ultra-low-latency execution. It translates domain-specific language (DSL) trading signals into optimized, cache-aligned, zero-allocation C++ code.

By parsing human-readable financial formulas into an Abstract Syntax Tree (AST) and emitting raw C++, AlphaParser bypasses the overhead of interpreted environments (like Python), generating execution paths suitable for high-frequency trading infrastructure.

Core Features
Custom Lexical & Syntax Analysis: Hand-rolled scanner and recursive-descent parser (no external dependencies like Flex/Bison) enforcing strict mathematical precedence.

Object-Oriented AST: Dynamically builds a validated Abstract Syntax Tree using modern C++ smart pointers for safe memory management during the compilation phase.

Semantic Safety: Pre-emission validation pass enforces type safety, bounds checking, and correct indicator arity (e.g., rejecting negative moving average periods).

Zero-Allocation Code Generation: Emits standard [[nodiscard]] inline C++ functions that evaluate signals using direct array indexing, completely avoiding runtime memory allocations.

Compilation Pipeline Example
Input DSL Signal (Strategy):

Code snippet
(SMA(20) > SMA(50)) && (price > EMA(10))
Emitted C++ Code (Execution):

C++
// Auto-generated by AlphaParser Compiler
// Highly-optimized zero-allocation signal evaluator
[[nodiscard]] inline bool evaluateSignal(
    const std::vector<double>& price, 
    const std::vector<double>& sma20, 
    const std::vector<double>& sma50, 
    const std::vector<double>& ema10
) noexcept {
    if (price.empty() || sma20.empty() || sma50.empty() || ema10.empty()) {
        return false;
    }
    
    const std::size_t idx = price.size() - 1;
    return ((sma20[idx] > sma50[idx]) && (price[idx] > ema10[idx]));
}
Build & Run Instructions
This project uses CMake and requires a compiler supporting C++17 or higher (GCC, Clang, or MSVC).

Bash
# Clone the repository
git clone https://github.com/YourUsername/AlphaParser.git
cd AlphaParser

# Configure and build using CMake
mkdir build && cd build
cmake ..
cmake --build .

# Run the compiler test suite
./alphaparser_demo
System Architecture
Lexer: Scans raw .dsl strings and tokenizes variables (price), indicators (SMA, STDDEV), operators, and literals.

Parser: Uses recursive descent to construct a hierarchical AST, strictly enforcing operational precedence (BODMAS/PEMDAS).

Semantic Analyzer: Traverses the AST to validate logic, trap type mismatches, and verify indicator parameters before generation.

Code Emitter: Applies the Visitor Design Pattern to map validated AST nodes to highly optimized C++ syntax.
